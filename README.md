# UCB × IBTM World 2026 — Uganda VR presentation

A WebXR presentation for the Uganda stand at IBTM World 2026, Barcelona. Everything is in one static file, `index.html`.

## Deploy on Vercel
Import this repository into Vercel. No build command is needed: choose the **Other** framework preset and leave the output directory blank (the root). Vercel then serves `index.html` at the project URL.

## View it
- **Meta Quest:** open the URL in Quest Browser and press **ENTER VR**. Point a controller and pull the trigger to click; squeeze the grip to go to the next scene.
- **Stand screen:** open the URL in Chrome and press **FULL SCREEN**. Arrow keys and presenter clickers (Page Up/Down) move between scenes, and M opens the menu.
